# 牛马电子功德安装、权限与更新

> **2026-10-21状态更正：** 当前官网为Mac0.9.4/904.14（Developer ID签名及苹果公证）和已签名Windows0.9.4。下文2026-10-11候选及签名状态属于历史记录；当前安装步骤见[安装与升级指南](INSTALL_UNSIGNED.md)，交接状态见[项目交接说明](PROJECT_HANDOFF.zh-CN.md)。不要据下文要求重新申请签名或重跑已完成验收。

更新日期：2026-10-11。当前公开版本和安装文件以官网下载登记为准；0.9.2 是本轮优化候选，构建完成不等于已公开发布。

## 先下载正确的文件

1. 从 `https://gongde.zqscreen.cn/download.html` 下载对应系统版本，也可使用项目 GitHub 正式发布页。
2. 基础客户端及内置木鱼免费，无需登录、领取码、关注或付款。扩展形象在统一形象库凭有效领取码免费领取。
3. Mac 使用 `.dmg`；Windows 使用 `-setup.exe` 安装程序，不是把 EXE 当 ZIP 解压。
4. 可核对公开 SHA-256。不要从陌生私信安装所谓“免权限版”，不要为了本产品关闭全局系统保护。

已发布 0.9.1 的 Mac 使用 Apple Development 证书，不是 Developer ID，也没有公证。Windows 0.9.1 未签名。系统仍可能提醒或阻止启动；GitHub 下载量不保证消除提示。

## Mac：安装与首次计数

1. 打开 DMG，将软件拖到“应用程序”，以后始终从该位置启动；不要同时运行 DMG 内和桌面上的副本。
2. 若系统阻止打开，确认官网来源和校验信息后，按系统提供的“隐私与安全性”中对应软件的“仍要打开”流程处理。无法确认文件来源时停止，不关闭 Gatekeeper。
3. 如需在其他软件中计数，在“系统设置 > 隐私与安全性 > 输入监控”允许当前这份“牛马电子功德”。
4. 按系统要求完全退出并重新打开软件。一般无需重启电脑，但实际结果以系统和监听状态为准。
5. 切换到普通文本编辑器，敲几次键，再在桌面正常点击，观察计数是否增加。仅点击宠物会增加，不能证明全局监听正常。

拖动宠物可调整位置；右键打开设置、形象、日历、关于和退出菜单。缺少全局权限时仍可点击宠物使用，不会要求提供账号或上传输入内容。

## 输入监控已勾选却不计数

1. 先退出软件，确认只保留一份位于“应用程序”的正式副本，然后正常重开。
2. 确认系统列表中的授权对应当前软件，而不是旧路径或旧身份。更新二进制、签名身份或位置后，旧记录可能不再适用。
3. 若仍无效，可在系统界面移除对应旧条目，再通过当前应用重新请求授权；这是恢复步骤，不是每次更新的必做操作。
4. 在普通应用中测试。密码输入、安全输入或系统安全界面可能限制事件，不能因此绕过系统保护。

不删除计数、日历或已安装形象来修复权限；不通过重签已发布安装包或后台修改权限数据库规避系统确认。

## Windows：安装与正常使用

1. 运行官网的 `niuma-merit-windows-<版本>-setup.exe`，按安装向导操作，使用安装后的快捷方式启动。
2. 若 SmartScreen、Smart App Control 或安全软件阻止，先核对来源和摘要，保留具体提示。仅在系统正常提供允许入口且确认可信时继续，不关闭全局防护。
3. Windows 没有照搬 Mac 的“输入监控”开关。在普通应用中进行键盘、鼠标和滚轮操作，观察数字变化。
4. 登录界面、UAC 安全桌面和部分高权限应用属于系统安全边界；不为扩大监听范围要求用户始终管理员运行。

Windows 本轮完整实机结果单独记录。构建通过、版本资源正确或合成输入成功，不等于真实安装使用已经通过。

## 导入形象

1. 官网领取一个形象得到 `.nmgpack`，多个形象得到一个 `.nmgpacks`，无需逐个下载。
2. 双击正式交付文件导入，或使用更换形象窗口的导入入口。创作者指南中的源包、示例和待审核原稿不是正式交付包。
3. 按导入结果打开“更换形象”选择。批次可能有重复或失败项，先看成功列表，不要因部分失败删除已正常安装的形象。
4. 下载到本地的合规交付包可随时导入并永久离线使用；服务器重下载期限或领取码到期不会让本地形象失效。

本轮 0.9.2 候选目标：单个成功项明确启用；多个成功项列出并允许选择；更换窗口标明当前和本次新增。只有对应平台实际验收后，发布说明才将其列为已交付。

## 更新与数据保护

1. 正常退出旧版，保留计数、日历、形象及设置，不把删除用户数据当成升级步骤。
2. Mac 替换“应用程序”中的同名软件；Windows 在原安装位置运行新版安装程序。不要通过多个随意命名的副本更新。
3. 重开后检查版本、原计数、原形象和自启动设置，再做一次普通应用中的计数检查。
4. 若权限或导入出错，保留错误信息及原安装包；回退替换应用程序，不删除数据。已发布 0.9.1 字节不被 0.9.2 候选覆盖。

客户端不自动更新、不联网校验账号或领取码，不会为了检查版本读取输入内容。

## 本地隐私边界

客户端将操作事件用于计数和动画，不保存按键内容、鼠标坐标、窗口标题、剪贴板、密码、截图或使用遥测。macOS 的系统权限本身具有接收输入事件的能力，不能宣传成操作系统只能授予“次数”。

本轮候选自检由用户主动触发，只临时使用事件次数、计数变化和相对时间。没收到事件表示尚未确认，不自动判为故障；自检不上传结果。

## 退出与卸载

先关闭不再需要的自启动，从宠物右键菜单正常退出。Mac 删除应用程序副本并按需移除相应权限条目；Windows 从系统“已安装的应用”使用卸载入口。用户计数和形象是独立数据，清理前另行确认，不能随应用升级顺手删除。

## 发布者：正式签名路径

2026-10-11 本机签名身份检查：1 个 Apple Development、0 个 Developer ID Application。没有读取或导出私钥；这不证明开发者账号未注册，也不证明已具备公证凭据。

- Mac 站外正式分发应使用 Developer ID Application 签名并提交苹果公证；证书申请涉及账户持有人或相应云证书权限。当前没有该证书，因此正式签名是明确外部依赖，不以开发证书冒充。[Apple Developer ID 说明](https://developer.apple.com/cn/help/account/certificates/create-developer-id-certificates)
- 中国大陆 Apple Developer App 的年度会员续订页面列示每年 688 元；实际资格、当前会员状态和结算以账户页面为准。本轮未购买、续订或代签协议。[Apple 注册与续订](https://developer.apple.com/cn/help/account/membership/enrolling-in-the-app/)
- Windows 保留现有 EXE 分发。Microsoft Store 对提交的 MSIX 采用商店签名，这不是给官网 EXE 自动签名；转 MSIX 需独立兼容验证。本轮不为签名改造安装渠道。[Microsoft MSIX 签名说明](https://learn.microsoft.com/zh-cn/windows/msix/package/signing-package-overview)
- Windows 直接 EXE 的证书或托管签名资格、报价与审核尚未确认，不报虚构价格，不把提交申请称作已获批。历史 SignPath 申请未获批准，没有已知下载量门槛保证获批。

正式签名准备顺序：确认身份与资格，取得专用证书或签名服务，配置仅引用凭据的发布流水线，对新版本签名并验证，再做普通用户路径安装验收。旧产物保持不变；不为积累“信誉”伪造下载或用户数据。
