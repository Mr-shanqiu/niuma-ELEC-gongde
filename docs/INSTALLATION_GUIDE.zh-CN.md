# 牛马电子功德安装与权限手册

适用于 macOS 与 Windows 公开测试版。

## 安装前请先确认

1. 只从官网 `https://gongde.zqscreen.cn` 或项目公开仓库下载。
2. 当前公开测试版未进行 Apple 或 Microsoft 商业代码签名，系统可能显示“无法验证开发者”“未知发布者”或安全提醒。
3. 下载后可使用官网公布的 SHA-256 与本地文件进行核对。文件名相同不代表内容一定相同。
4. 桌面客户端不需要注册账号，也不会连接支付、短信或网站账户。下载和付费发生在网站，计数发生在本地软件。

## macOS 安装

1. 下载 macOS 的 DMG 安装包。
2. 打开 DMG，将“牛马电子功德”拖入“应用程序”文件夹。
3. 在“应用程序”中打开软件。如果系统阻止启动，先关闭提示。
4. 打开“系统设置” > “隐私与安全性”，在页面下方找到被阻止的软件，确认名称和下载来源后点击“仍要打开”。
5. 首次启动后，软件会申请“输入监控”权限。打开“系统设置” > “隐私与安全性” > “输入监控”，允许“牛马电子功德”。
6. 完全退出软件后重新打开。无需重新启动电脑。

旧版 macOS 的入口通常是“系统偏好设置” > “安全性与隐私” > “隐私” > “输入监控”，修改前可能需要先点击左下角锁形按钮。

### 如果“输入监控”中出现多个同名项目

1. 退出所有“牛马电子功德”进程。
2. 删除不再使用的旧副本，只保留“应用程序”文件夹中的最新版。
3. 在“输入监控”列表中移除旧条目。
4. 重新打开最新版，再允许一次权限。

后续更新请始终替换“应用程序”文件夹中的同一个软件，不要同时保留多个副本。

## Windows 安装

1. 下载 Windows ZIP 安装包并完整解压到固定文件夹，不要直接在压缩包内运行。
2. 运行“牛马电子功德”。
3. 当前版本未进行商业代码签名，Microsoft Defender SmartScreen 可能显示“未知发布者”。只有在文件来自官网且 SHA-256 核对一致时，才选择“更多信息” > “仍要运行”。
4. Windows 通常不会单独显示“输入监控”授权窗口。软件启动后即可统计普通桌面环境中的键盘、鼠标按键和滚轮操作。

登录界面、UAC 安全桌面和部分高权限程序中的输入不会被普通权限的软件统计，这是 Windows 的系统安全边界。

不要为了运行本软件永久关闭杀毒软件。若安全软件拦截文件，请先核对官网来源与 SHA-256；无法确认时不要运行。

## 为什么需要“输入监控”权限

系统级计数要求软件在其他应用处于前台时仍能收到键盘和鼠标事件。macOS 将这类能力统一归入“输入监控”。

需要如实说明的是：这项系统权限在技术上允许获授权的软件接收更丰富的输入事件。系统无法只授予“次数”而完全禁止按键标识。因此，安全性取决于软件实际如何处理这些事件。

当前桌面客户端只把以下操作转换为一次计数：

- 键盘按下一次。
- 鼠标任意按键点击一次，包括左键、右键和其他按键。
- 一段连续滚动手势计为一次，停止后再次滚动才开始新的一次。

当前桌面客户端不会保存或上传：

- 具体按键和输入文字。
- 鼠标位置和点击目标。
- 当前窗口标题或正在使用的软件名称。
- 剪贴板、截图、文件内容和密码。
- 设备标识、使用统计或遥测数据。

桌面客户端不包含广告、联网同步、遥测和自动更新。官网可以提供下载、手机号验证和支付，但这些网站功能与本地计数客户端相互独立。

## 使用形象包

1. 从官网下载扩展名为 `.nmgpack` 的形象包。
2. 双击形象包，系统会交给“牛马电子功德”导入。
3. 右键点击桌面形象，选择“更换形象”。
4. 在已经安装的形象中点选需要的形象，然后确认。

形象包只包含经过审核的图片、动画参数和说明信息，不能修改计数、权限、联网或其他程序功能。

## 常见问题

### 已允许输入监控，但没有计数

完全退出软件后重新打开；确认运行的是“应用程序”文件夹中的最新版，并检查“输入监控”列表中允许的是否为这一份软件。

### 点击形象会计数，但在其他软件中输入不计数

这通常表示全局输入监听没有生效。请重新检查输入监控权限，并在修改权限后退出、重新打开软件。

### 更新后系统再次询问权限

未签名测试版在文件位置或程序身份发生变化时，macOS 可能将其识别为另一份软件。请用新版直接替换旧版，不要保留多个副本。

### 是否需要重新启动电脑

不需要。权限变更后只需完全退出并重新打开“牛马电子功德”。

## 开机自启动与退出

右键点击桌面形象，可使用“自启动”“功德日历”“更换形象”“关于”和“退出”。自启动默认由用户决定，不会在未选择时强制开启。

## 卸载

1. 先从右键菜单退出软件。
2. 如果启用了自启动，先在菜单中关闭。
3. macOS 用户可在“输入监控”中移除该软件，然后删除“应用程序”中的软件。
4. Windows 用户可删除解压后的程序文件夹。

如对下载来源或文件校验结果有疑问，请不要绕过系统警告运行文件。
