# 牛马官网首页功能展示方案

日期：2026-10-20  
状态：待用户审核，仅形成方案，未修改或发布官网。

本方案围绕当前 0.9.4 客户端，把功德计数、下班倒计时、功德日历和幽默气泡四项核心功能放进首屏横向切换展示。首屏结束后立即进入形象库，让功能介绍完整，同时保持图库距离很近。采用用户已确定的主题与首屏介绍。

本方案只调整官网的介绍、展示与入口。现有客户端功能、基础免费与扩展形象获取规则继续沿用，付款、群码和交付机制不因首页改版而改变。它是现有《全新官网 UI 与用户旅程方案》的首页内容补充；本方案中的新标题与功能展示顺序，替代旧稿对应的首页建议。

## 1 当前首页缺少什么

当前首页结构为首屏木鱼互动、形象库、三步上手。主标题是“你忙你的，它陪着”，介绍强调“点一下会动”和桌面陪伴。这样的表达能说明形象有趣，却没有充分呈现当前客户端的用途。

主要缺口有三处：

- 用户看不到下班倒计时、今日加班和日历记录，容易把软件理解成只有一个会动的木鱼。
- 幽默气泡、节日文案和文案包没有展示，产品最有性格的部分被藏在实际使用中。
- 基础客户端包含哪些功能、哪些是可选的扩展形象，没有集中说明，容易误以为要先购买或领码才能体验。

解决方式是把核心功能收进首屏的横向展示，不在首屏与形象库之间增加纵向功能区。附属能力放在对应功能说明或问答中。首页不逐项罗列菜单，也不增加一面长篇功能说明墙。

## 2 首屏使用的正式文案

主标题按两行排版：

> 现代键鼠牛马，  
> 无量电子功德

介绍直接使用用户确认的版本：

> 敲键盘、点鼠标，功德自动累积。看看今天攒了多少，再看看离下班还有多久。

主按钮：**免费下载客户端**。  
次按钮：**挑选喜欢的形象 ↓**，直接滚动至紧接首屏的形象库。  
下载按钮附近的辅助说明：**支持 Windows / Mac · 基础木鱼免费 · 无需登录**。  
再放一行低强调说明：**全程本地运行，只统计操作次数，不读取输入内容。**

“全程本地运行”描述安装后的客户端。官网挑选、付费或领取扩展文件需要网络，详细解释放在问答中。

首屏左侧固定主标题、介绍和下载入口，右侧横向切换四项功能画面及对应短文案。切换功能时不替换主标题和下载按钮，用户随时都能下载或直接去图库。默认页保留现有木鱼互动；其余页展示下班倒计时、功德日历和幽默气泡。

计数演示只响应用户在网页上的主动点击，不监听网页外操作；倒计时示例标注“客户端效果示意”，避免被理解成正在读取访客的下班设置。气泡只出现在对应展示画面中，不漂浮到图库或遮挡其他页面内容。

首屏不强制占满整个浏览器高度，也不让四项功能分别占四个纵向屏幕。常见电脑窗口中，首屏下缘应能看到图库标题；较高窗口尽量露出第一排形象。具体高度与换行按真实画面确定，不为露出图库而缩小截图至不可读。

## 3 推荐的首页顺序

```text
顶部导航：功能介绍 / 挑选形象 / 安装帮助 / 免费下载

首屏横向展示

左侧固定：一句说明 + 免费下载 + 本地运行说明 + 挑选形象
```

“功能介绍”返回首屏展示，“挑选形象”直接跳到图库。首屏与图库之间不插入独立功能卡片、说明墙或宣传大图。群码入口放在形象库与获取流程中，保留清楚可见的免费领取路线。用户不必看完所有功能页才能进入图库。

## 4 首屏横向切换的内容与交互

右侧展示区使用相同的容器尺寸，每次展示一项功能。四个功能名称“功德计数 / 下班倒计时 / 功德日历 / 幽默气泡”常驻在展示区下方，当前项有清楚的选中状态。用户一眼能知道还有哪些功能，不只看到没有含义的四个圆点。

每页保留一个短标题、一至两句介绍和真实客户端画面。左右箭头切换上一项和下一项，也可直接点功能名称；循环切换时页面高度和图库位置保持稳定。

| 功能 | 推荐标题与正文 | 对应画面 |
| --- | --- | --- |
| 键鼠计数和形象动作 | **忙没白忙，功德加一。** 敲键盘、点鼠标、滚动一下，桌面小伙伴跟着动，今天的功德也跟着攒。 | 真实木鱼、清楚的数字与一次“+1”反馈。角落提供“点一下体验”，演示由访客主动触发。 |
| 下班倒计时 | **距离下班，还有多久？** 设好下班时间，剩余多久一眼就能看到。时间到了，就接着显示今日加班。 | 同一形象下的“距下班”和“已加班”两种实际状态，用两个紧凑示例并列说明。 |
| 功德日历 | **这个月，功德没少攒。** 打开日历，看看每天攒了多少功德，也能回看留下的加班记录。 | 当前正式版日历截图，日期用深色，功德与加班时间保留客户端金色；截取可读的月份和日期详情。 |
| 幽默气泡 | **差不多得了，老板买车又不写你名字。** 持续忙碌或操作密集时，它偶尔冒一句损友式关心。平日会嘴欠，节日也有专属台词，同一句七天内不重复。 | 实际气泡的圆角、字体、尺寸与关闭按钮。示例必须选用内置文案库（`src/reminder_catalog_data.h`）中真实存在的句子，提供“再看一句”，只在当前展示页内部切换。 |

四个功能名称下方放一句低强调说明：**这些功能都在免费客户端里；下班倒计时可按需开启。**

自动切换建议每页停留约 7 秒，并提供暂停按钮。鼠标进入展示区、键盘焦点进入、用户点箭头或功能名称、操作木鱼或“再看一句”后，自动切换暂停；手动操作后保持暂停，直到用户主动恢复。页面离开首屏或浏览器标签隐藏时也停止轮播，减少无意义播放。减少动画模式下默认手动切换。

横向切换只发生在展示区内，不接管鼠标滚轮的纵向滚动。用户往下滚一次就能进入图库，不需要先看完四页，也不让滚轮触发横向翻页。切换采用简短平移或淡入过渡，约 250—350 毫秒，不增加翻页音效。

这里不展示提醒阈值、内部状态机、文案签名、构建号等实现细节。网页自动切换和气泡示例只用于介绍功能，与客户端真实提醒频率无关。气泡介绍不写“每 30 分钟提醒”，因为实际机制根据活动状况触发，并非固定时间闹钟。节日文案同样需要满足活动触发和适用条件，不承诺节日当天必定弹出。

“加班”是根据用户设置的下班时间与客户端保存的本地快照显示，不能宣传成准确工时统计、考勤或实际离岗识别。这一点在问答中用一句话说明，首屏展示仍保持轻松直观。

## 5 形象库如何承接

图库紧接首屏横向展示，保留现有搜索、真实预览、分页、已选清单和两条获取路线。它承接的是“喜欢这个软件，想换一个形象”，不承担全部产品介绍。首屏轮播未看完、尚未互动或自动切换暂停，都不影响图库加载和正常选择。

标题建议：**换个形象，继续攒功德。**  
介绍建议：**基础木鱼免费自带。喜欢别的样子，也可以换上它。扩展形象每个 ¥1，或凭粉丝群码免费领取。**

图库旁边简短说明：**更换形象不清空功德和日历记录。**

展示与交互继续使用实际在架形象，不写固定作品总数，不把下架作品当作可获取内容。点击卡片只负责选择，悬停只负责预览。金额、每批数量限制、保存文件后的长期本地使用规则，沿用现有流程。

不在图库上方堆放完整付款条款；用户决定获取扩展时，仍须在原获取流程看到本次下载和重新下载的准确规则。

## 6 其余能力放在哪里

以下能力都应能在官网找到，但不需要各占一块大屏：

| 能力 | 推荐位置与表达 |
| --- | --- |
| 拖动桌面小伙伴 | 上手步骤的小字：“拖到顺手的位置，右键打开功能菜单。” |
| 登录后自动启动 | 上手说明或问答：“可在右键菜单中管理登录后自动启动。”不宣传成需要每天手动打开。 |
| 中英文界面与文案 | 首屏展示区的轻量说明：“界面跟随系统语言，支持中文和英文。”客户端内**没有**语言切换菜单（macOS 读 `NSLocale.preferredLanguages`，Windows 读 `GetUserDefaultUILanguage`），不得宣传成可在应用内切换。 |
| 地区适用的节日文案 | 幽默气泡说明中带出；不用“所有地区、所有节日”这样的承诺。 |
| 中文和英文各 800 条内置文案 | 气泡展示页或问答：“内置中文、英文文案各 800 条，包含日常和节日内容。”不当成 1600 条都能在同一种语言下轮换。 |
| 文案包导入 | 气泡问答：“官方文案包下载后双击即可在本地导入，无需重新安装客户端。”官网没有实际可供下载的新包时，不放不可用按钮。 |
| 单个或批次形象包导入 | 形象库后的小字及导入帮助：“下载形象文件，双击导入，无需解压。”不把选择扩展形象写成必经步骤。 |
| 本地使用与输入权限 | 下载按钮旁一句说明，问答再解释 Mac 输入监控的用途。 |

这张表用于检查信息是否齐全，最终页面不直接照搬成一张技术功能表。

## 7 上手步骤和问答文案

现有首页三步以“安装、挑形象、导入”为主，容易让新用户以为基础使用也必须获取形象包。建议改为：

1. **下载并安装**：支持 Windows 和 Mac，基础木鱼免费自带。
2. **打开客户端**：Mac 按系统提示开启输入监控，允许统计键鼠操作次数。
3. **开始积攒**：正常使用电脑就会计数；右键可看日历、设置下班时间和更换形象。

步骤下提供“查看安装图解”，另设一行“想换形象？查看导入方法”。已有的横向安装图解继续承担详细操作说明，首页不再重复一套长教程。

问答默认只展开最常见的一项，其余可折叠：

**免费版包含什么？**  
客户端和基础木鱼免费，功德计数、下班倒计时、功德日历与幽默气泡都随客户端提供。可选的扩展形象按页面规则获取。下班倒计时的显示形象取决于当前选用的形象包（例如「下班按钮·第一人称」是形象包，不是独立功能）。

**本地运行是什么意思？**  
安装后的客户端不联网，不需要账号或联网激活。它只统计操作次数，不读取你输入的文字；到官网获取新的形象或文案文件时才需要网络。

**Mac 为什么需要输入监控？**  
这是 macOS 接收其他应用中键鼠事件所需的系统权限。牛马用它统计次数，不读取具体输入内容。查看权限图解。

**今日加班就是实际工时吗？**  
它按你设置的下班时间显示并保存本地时间快照，不判断你是否仍在工作，不用于考勤。

**气泡是定时弹出的吗？**  
气泡根据持续忙碌或密集操作等条件偶尔出现，不是每隔固定时间弹一次。同一句文案七天内不重复。

文案包的获取与导入说明可以接在气泡问答下，不再增加独立的大功能模块。

## 8 视觉和素材要求

整体沿用当前官网的品牌识别，改进信息层级。主视觉以真实客户端、清楚的大数字和足够留白为主，不再用抽象卡通图代替软件界面，也不为首页重新设计一套与客户端不一致的日历或菜单。

- 电脑端内容区建议最大宽度 1180—1240 px；首屏标题约 56—68 px，介绍约 17—19 px，按实际窗口调整换行。
- 四个横向展示页采用相同外边距和容器高度；文字两至三行即可，画面优先保证数字和气泡可读。切换时不让首屏忽高忽低，也不推动图库上下跳动。素材空间不足时减少装饰，不缩小整张截图到无法辨认。
- 用当前正式客户端素材：木鱼完整动作、实际下班与加班状态、金色功德日历、现行气泡。截图使用示例数据，不包含用户真实历史或桌面私人内容。
- 桌面照片或浅色桌面背景只用于说明摆放效果，不加入假的操作系统控件。图例中的按钮、字体和菜单比例要与当前 Mac、Windows 实际界面对应。
- 多个动画不同时高频播放。只让当前可见、正在体验的区域播放；日历使用静态截图即可，倒计时不需要每张示例都运行计时器。
- 首屏默认页资源优先加载，其余功能素材延后准备；图库首排同时保持及时加载，不等待轮播四页全部就绪。复用现有形象资源和预览播放器。继续禁止安装包自动预取，访客明确点击下载后才请求安装包。
- 保留键盘可操作、文字对比度和减少动画模式；功能标题及介绍使用网页文字，不全部烘焙进图片。

安装包大小在下载按钮附近按正式记录显示，首页不写固定内存或 CPU 数字，也不使用“几乎不占 CPU”这样的未量化承诺。

**版本口径更正（2026-10-20）**：`services/gongde-payments/src/free-distribution/installers.json` 实测已含 **0.9.4**（macOS `...-0.9.4-90413-...`、Windows `...-0.9.4-signed-3`），此前“仓库内仍是 0.9.1”的结论不成立。首页下载链接指向 `download.html`，其数据由该文件驱动，因此不需要在本轮改版本号。

## 9 中文与英文同步范围

本次首页若进入实施，中英文需要同时覆盖新标题、介绍、四项功能、轻量说明、问答和图片替代文本。英文应表达同样的功能，幽默标题可以做文化适配，不必生硬翻译“牛马”和“功德”的双关。

客户端截图可以按对应语言制作，不能只换网页标题、仍让英文用户面对整套中文功能截图。官网语言也不应被描述成会改变客户端语言。其他页面中已经与当前客户端冲突的介绍，例如缺少新增功能或沿用旧安装前缀的提示，实施时只做与本轮直接相关的文字对齐。

## 10 后续实施范围和验收标准

用户确认方案后，建议一次完成首页文案、首屏横向切换、真实素材、中英文对应内容和相关问答，然后再发布。首页不增加纵向功能区。沿用当前业务接口和形象获取流程，不增加客户端开发。

部署已由牛马项目自行承担，走 `deploy/production/scripts/deploy-gongde-assets-client.sh`（专用密钥、命令白名单、哈希校验、支持回滚）。ACE 侧 `deploy/production/README.md` 中“由桌球主控执行”的描述属于历史口径，以牛马当前实际入口为准。

相关文件预计包括 `website/index.html`、首页使用的现有样式与脚本、语言资源，以及确有对应过时内容的帮助或问答页。具体改动以实施时确认的线上基线为准。

验收应围绕以下结果：

- 新用户看完首屏，能说出“键鼠计数”和“看下班时间”两个用途。
- 首屏四个功能名称直接可见，用户可点名称或箭头切换；不必等待自动轮播才知道还有哪些功能。
- 图库紧接首屏；未看完功能页也能直接向下浏览或点击“挑选喜欢的形象”进入图库，页面不劫持纵向滚动。
- 常见电脑窗口中尽量露出图库标题；功能切换不改变首屏高度或引起图库跳动。
- 不进入形象购买流程，就能找到四项核心功能，以及它们随免费客户端提供的说明。
- 不把扩展形象导入误解成使用基础木鱼的前提。
