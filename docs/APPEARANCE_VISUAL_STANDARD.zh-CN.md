# 形象视觉与官网预览规范

## 2026-10-11 公开网页衍生预览补充

本节按产品体验优化方案 1.0 补充并替代下文历史规则中“网页只能复制原始 PNG、不能缩图”的限制。原始安装素材、审核版本、清单和签名仍是不可改写的真相；网页可从该确切版本生成专用封面与缩小后的动作图层。

公开网页封面按 240×170 显示，动作素材使用 480×340 的衍生规格。生成时统一换算坐标、锚点、旋转中心和完整动作包围盒，不手工替换任何角色部件，不修改安装包字节。衍生地址绑定源版本、渲染器版本与输出规格，旧公开版本继续可回滚。

每次新增作品或修改素材使用以下轻量检查表；没有对应实际结果的格子保持待验收，不能由安全审核或编译结果代填。

| 检查项 | 合格标准 | 证据 |
| --- | --- | --- |
| 实际显示尺寸 | 240×170 卡片中主体与主要动作可辨认 | 电脑端实际截图 |
| 透明边缘 | 无明显杂边、异常不透明底色 | 浅色、深色背景观察 |
| 动作范围 | 全程不裁切必要部件，动作后回到静止姿态 | 悬停或键盘播放 |
| 原包一致 | 角色、图层、动作方向与安装后形象一致 | 已审核原包与客户端已有验收 |
| 异常恢复 | 暂时失败保留封面与选择能力，提示可修复动作 | 受影响作品的针对性检查 |

## 唯一真相（以下为历史安装素材与原始预览规则）

每个形象的图片、图层位置、锚点、关键帧和缩放只能定义在形象包的 `manifest.json` 中。macOS、Windows、官网预览和制作工具都必须读取同一份清单，禁止在官网 CSS、客户端场景代码或发布脚本中重新手写角色专属坐标和动画。

官网发布时，`scripts/generate-website-previews.mjs` 只复制审核通过的形象包清单及其声明的 PNG 文件。浏览器依据清单渲染，不修改图片、不拆分图层、不重新解释锤头、手臂、头部或其他部件。

## 固定画布区域

- 完整画布：`240 x 250`。
- 形象区域：底部 `240 x 170`。
- `+1` 区域从 `y=174` 开始。
- 总数区域位于顶部，任何形象图层不得进入。
- 图层使用左下角坐标系；网页只负责将相同坐标换算成浏览器的左上角坐标系。

## 统一视觉占比

所有可见图层在形象区域内的裁切后联合边界必须满足：

- 宽度：`150–220`。
- 高度：`120–170`。
- 主体应以 `x=120` 为视觉中心。
- 站立或落地形象应以 `y=0` 为共同基线。
- 动作关键帧不得遮挡 `+1` 和总数区域。
- 官网对所有形象只使用同一个整体投影比例，不允许角色专属网站缩放。

不同宽高比的角色不要求像素面积完全相等，但在相同卡片中应具有接近的视觉重量。横向角色应适当缩小清单中的图层框，不能通过官网单独缩放修正。

## 新形象上架约束

1. 先在形象包清单中完成构图和动画。
2. 同一形象包分别由 macOS、Windows 和官网渲染。
3. 三端静止状态、动作方向、锚点和接触位置必须一致。
4. 通过统一视觉边界检查后才能进入官网形象库。
5. 发现比例问题时修改形象包清单并重新发布，不得只修官网截图或 CSS。

## 2026-09-23 同源发布补充

- 19 个付费形象的唯一可编辑源仍是 `assets/appearance-packs/`。官网必须逐字节复制原始 manifest 和 PNG；禁止只为官网缩图、重绘、替换零件或增加形变。
- 官网 `pack-player.js` 按客户端规则使用左下原点、逐段线性插值、相同锚点和变换顺序。单次演示采用当前系统孤立输入的初始时长（macOS 231ms / Windows 220ms）；悬停仅定时重新触发，不改动关键帧。客户端连续输入的自适应节奏不等于官网自动演示的触发间隔。
- 默认木鱼不是可导入的示例包。预览构建直接从 macOS / Windows 默认木鱼绘制代码提取位置、裁切与转轴，并复制客户端原始木鱼和木棒文件。两个平台现有默认绘制存在差异，网页按当前系统显示，不宣称两个平台历史二进制像素完全相同。
- 选择窗口用的 `preview.png` 必须由实际静止帧渲染，不能继续使用与新图层不同的旧宣传图。缩略图是派生物，不能反过来作为动作图层。
- 官网发布清单记录每个文件 SHA-256，以及整个形象源目录的聚合指纹。下单前前后端核对该指纹，不一致时拒绝新建订单，请用户刷新；这是版本一致性约束，不是付费内容防复制机制。
- 下载构建先解析 `current` 到不可变资产版本路径，再读文件，防止发布切换时混用两个版本。
- 改动有状态的动作须回到相同静止姿态。树干、地面、底座保持固定；金币应落入盆内并被前景遮挡；气泡向上；跳跃先上升再落地；肢体转轴应在连接处，不能靠缩放整张图假装动作。
- “源文件指纹一致”和“浏览器逐帧看过”不等于真实付款下载、双端安装验收完成。发布记录必须分别说明。
