# 0.7 客户端与 0.8 官网实施记录

日期：2026-09-16

## 客户端 0.7.0

- 基础安装包内置：默认木鱼、招财猫、仓鼠跑轮、海狮拍肚皮。
- 小鸡啄米从内置列表移出，改为独立永久免费 `.nmgpack`。
- 兼容 Schema 1 永久免费包。
- 支持 Schema 2 P-256 签名的24小时首次导入包。
- 限时包只在首次导入时检查时间；成功后永久离线使用。
- 客户端仍无网络、遥测、账号、支付或自动更新。

## 官网 0.8.0

- 完成中英文静态首页。
- 完成产品演示、基础形象、免费形象、隐私说明和双平台下载区域。
- 小鸡啄米免费包可直接下载。
- 当前下载按钮预留到 GitHub `v0.7.0` Release，发布后生效。
- 网站没有登录、支付、用户上传或第三方追踪脚本。

## 真实验收

- macOS Universal 2：`x86_64 + arm64` 构建成功。
- macOS 双语计数、日历、四形象选择、动画状态机通过。
- macOS 离线静态审计通过。
- macOS ZIP：`4,928,067` 字节，低于不含独立形象包的 `10MB` 上限。
- macOS DMG：`4,967,989` 字节，磁盘镜像校验通过。
- 小鸡啄米免费包：`1,502,433` 字节。
- P-256 有效限时包首次导入成功。
- 已过期限时包被拒绝，且不会损坏已安装形象。
- 官网桌面与手机宽度完成本地浏览器渲染检查，全部形象资源加载成功。

## 尚未完成

- Windows 0.7.0 必须进入 Windows MSVC 或 GitHub Actions 完成真实构建测试。
- GitHub `v0.7.0` Release 尚未创建，因此官网客户端按钮目前是预留链接。
- 官网尚未部署到正式域名。
- 支付、登录和创作者平台不属于本轮实施。
