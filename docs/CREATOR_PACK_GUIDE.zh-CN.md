# 免费创作者社区：封装、投稿与分享指南

状态：封装与投稿分享规范，不是上线或验收记录。投稿、浏览分享和免费文件交付的开放状态，以公开页面实时提示为准；本指南不表示已完成客户端运行验收或完整闭环验收。

独立引用页面为 `website/creator-guide.html`；开放后的官网页面路径为 `/creator-guide.html`。本指南只说明外部制作与投稿，不提供素材编辑、在线封装或代制作工具。

字段以 [pack-validation.ts](../services/gongde-payments/src/creators/pack-validation.ts) 的 `SourceManifest` 和 `validateCreatorSourcePack` 为准；数值预算取自其导入的 [policy.ts](../services/gongde-payments/src/creators/policy.ts) 中 `CREATOR_UPLOAD_LIMITS`；作品 ID 由 [types.ts](../services/gongde-payments/src/creators/types.ts) 的 `creatorWorkId` 构造。这是源码说明，不是验证记录。

## 1. 谁需要账号，谁不用

创作者使用登录用户名 `username`、密码 `password` 与恢复码管理投稿，另填用于公开展示的昵称。不要求绑定手机号或邮箱。注册后私密保存恢复码；恢复账号后保存新恢复码，不再使用旧码。不要把密码、恢复码、会话信息、官方购买凭据或旧权益码交给外部 AI，也不要写入包内。不要依赖短信或邮件找回账号。

下载者匿名使用社区，无需注册、付款或权益码。社区作品允许免费下载与永久离线使用，不适用原官方付费订单的 24 小时下载和首次导入期限。原官方付费价格、购买流程、订单期限和旧权益码规则均不因社区改变。

## 2. 从作品 ID 到审核分享

1. 功能开放后，在 `creator.html` 注册或登录，保存自己的恢复码。
2. 先创建作品资料草稿，取得平台分配的完整作品 ID，再准备封装。作品 slug 是 ID 的一部分，创建后不能通过更换包内 ID 冒用别的作品。
3. 把作品 ID、公开署名与本指南交给自己的外部 AI 或制作工具，由该工具制作合法素材并封装单个 `.nmgpack`。工作台只提供 ID 和要求，不生成素材、不代封装。
4. 在对应作品下上传 `.nmgpack`，根据校验提示修正文件，再查看上传素材的真实预览，检查静止状态和动作。字段校验通过不代表版权审核或双端运行验收通过。
5. 确认自己有权分享全部素材，并允许平台审核、展示、免费分发及用户免费下载、永久离线使用，再提交审核。
6. 审核通过后公开分享作品页面，路径形式为 `community.html?work=<平台分配的作品ID>`。未通过或尚在审核中的稿件不能当作已发布作品分享。

已公开版本与介绍保持审核快照；修改草稿或上传新版本不能绕过审核替换公开内容。下架停止新的社区获取，不回收已合法导入的离线副本。免费分享不表示版权转让，也不自动许可未经授权的再发布、转售或其他用途。这里描述产品流程与声明范围，不作个案法律结论。

## 3. 上传源包，不是整批交付包

上传文件必须为单个 `.nmgpack`，其内容是普通单卷 ZIP，根目录只含 `manifest.json` 和 1 至 7 张已声明 PNG，共 2 至 8 个文件。

- ZIP 压缩方法仅为 stored（0）或 deflate（8），全局注释为空；不要使用 ZIP64、加密、分卷、数据描述符、自解压外壳或额外拼接数据。
- 不包含子目录、链接、`.DS_Store`、`__MACOSX`、脚本、可执行文件、SVG、视频或字体文件。
- PNG 文件名匹配 `^[a-z0-9][a-z0-9_-]{0,59}\.png$`：基名 1 至 60 位，只用小写 ASCII 字母、数字、下划线、短横线，并以字母或数字开头。
- 每张 PNG 必须被 `preview` 或某层 `image` 引用；每个引用必须有对应文件。预览与图层可以共用一张 PNG，不允许隐藏未声明文件。
- `.nmgpacks` 是平台给下载者的一次整批导入文件，不用于创作者投稿；不要把买到的官方交付包换名投稿。
- 投稿只接受 Schema 1 或 3，不接受 Schema 2。投稿 manifest 不能包含 `license`、签名、付费字段或其他白名单之外的字段；不要把平台交付包的字段复制进源包。

平台按源码检查 ZIP 本地与中央目录、CRC、解压预算、PNG 结构及压缩流、字段和作品身份。不要以普通解压软件能打开作为投稿已通过的依据。

## 4. 源码投稿预算

这些是社区上传源包的预算，不用于改变原官方付费包或客户端的其他限制。`MiB = 1024 × 1024` 字节，`KiB = 1024` 字节。

- 压缩包最多 8 MiB；展开后全部文件合计最多 12 MiB。
- `manifest.json` 最多 64 KiB；根目录最多 8 个文件。
- PNG 宽、高分别为 1 至 2048 像素；所有图片的 `宽 × 高 × 4` 总计最多 64 MiB，RGB 图片也按此 RGBA 内存预算计入。
- PNG 为 8 位 RGB 或 RGBA、非交错静态 PNG；不使用 APNG、索引色、灰度或 16 位 PNG。不添加校验器不接受的关键块，例如 `PLTE`。
- 图层为 1 至 6 个，每层关键帧为 1 至 8 个。

## 5. Manifest 精确字段

根对象、图层对象和关键帧对象均使用严格白名单。不要增加图层 `id`、注释字段、网络图片地址或自定义扩展字段。

| 对象 / 字段 | 源码要求 |
| --- | --- |
| 根对象字段 | `schema_version`、`id`、`version`、`name_zh`、`name_en`、`author`、`publisher`、`review_id`、`canvas_width`、`canvas_height`、`preview`、`plus_y`、`layers` |
| `schema_version` | 只能是数字 `1` 或 `3` |
| `id` | 必须完全等于该账号、该作品的平台分配 ID：`creator.<32位小写十六进制创作者ID>.<slug>`；不自行编造、修改或使用官方 / 他人 ID |
| 作品 `slug` | 1 至 32 位小写字母、数字或短横线，首尾均为字母或数字；以创建作品时的平台值为准 |
| `version` | 1 至 32 位 ASCII 字符，匹配 `^[a-zA-Z0-9][a-zA-Z0-9._-]*$` |
| `name_zh`、`name_en`、`author` | 各 1 至 80 个字符，不得全为空白，不含 U+0000 至 U+001F 或 U+007F 控制字符；`author` 使用可公开的署名 |
| `publisher`、`review_id` | 投稿时固定为 `"community"`、`"pending"`，发布后的交付字段由平台处理 |
| 画布和计数位置 | `canvas_width = 240`、`canvas_height = 250`、`plus_y = 174` |
| `preview` | 根目录 PNG 文件名，不是 URL |
| Schema 1 图层字段 | 仅 `image`、`frame`、`anchor`、`keyframes`，没有图层 `id` |
| `frame` | 四个有限数 `[x, y, width, height]`；x 为 -240 至 480，y 为 -250 至 480，width / height 为 1 至 480 |
| Schema 1 额外位置约束 | `y >= 0` 且 `y + height <= 170`；不要误写成额外的 x 方向白名单限制 |
| `anchor` | 两个有限数 `[x, y]`，各为 0 至 1 |
| Schema 1 关键帧字段 | 仅 `t`、`x`、`y`、`rotation`、`scale`、`alpha` |
| `t` | 0 至 1，第一帧必须为 0，其后经 `Math.fround` 转为单精度仍严格递增；最后一帧不强制为 1 |
| 关键帧位置与动作 | x / y 各 -480 至 480；rotation 为 -180 至 180；scale 为 0.1 至 4；alpha 为 0 至 1，均为有限数 |
| Schema 3 图层新增字段 | 每层必须增加 `interpolation`，只能为 `"linear"` 或 `"smoothstep"` |
| Schema 3 关键帧新增字段 | 每个关键帧必须增加 `scale_y`，为 0.1 至 4 的有限数 |

Schema 1 不接受 Schema 3 的新增字段。Schema 3 不使用上述 Schema 1 的 y 保留区域额外检查，但仍需要查看实际预览与审核，不代表任意布局都能正常显示。

## 6. Schema 1 封装示例

以下只是结构示例，不是可下载作品、投稿记录或审核结果。必须把示例 `id` 换成自己先创建作品取得的 ID；名称与署名也要替换。`sample.png` 需由你自行制作为合规 PNG，本文不提供图片文件。

```text
根目录
manifest.json
sample.png
```

```json
{
  "schema_version": 1,
  "id": "creator.0123456789abcdef0123456789abcdef.example",
  "version": "1.0.0",
  "name_zh": "示例形象",
  "name_en": "Example Appearance",
  "author": "你的公开昵称",
  "publisher": "community",
  "review_id": "pending",
  "canvas_width": 240,
  "canvas_height": 250,
  "preview": "sample.png",
  "plus_y": 174,
  "layers": [
    {
      "image": "sample.png",
      "frame": [30, 20, 180, 140],
      "anchor": [0.5, 0.5],
      "keyframes": [
        {"t": 0, "x": 0, "y": 0, "rotation": 0, "scale": 1, "alpha": 1},
        {"t": 0.5, "x": 0, "y": 3, "rotation": 2, "scale": 1, "alpha": 1},
        {"t": 1, "x": 0, "y": 0, "rotation": 0, "scale": 1, "alpha": 1}
      ]
    }
  ]
}
```

若改用 Schema 3，需要同时把根对象 `schema_version` 改为 `3`、给每层添加 `interpolation`，并给每个关键帧添加 `scale_y`（例如 `1`）。不要给图层添加 `id`，也不要给根对象添加 `license`；其他字段和预算不变。

使用前先把下列尖括号占位内容换成平台分配的 ID、公开署名与作品名；这段说明不是 manifest，不要把它直接当作上传文件。

## 8. 下载者一次整批导入

功能开放后，在 `community.html` 选择已审核发布的社区作品；多个作品下载成一个 `.nmgpacks` 文件，单个作品使用 `.nmgpack`。安装并打开支持社区包的客户端后，直接双击文件，一次核验并导入整批，无需解压或逐个找文件；随后从“更换形象”选用。

社区下载不需要账号、付款或权益码，不设官方付费的 24 小时下载与首次导入期限。已合法导入的副本可永久离线使用；下架不回收离线副本。安装步骤见 `website/install.html#community-import`，原官方付费导入说明仍保留在 `#appearance-import`。

## 9. 投稿者自查与隐私

- 确认素材、署名及使用的外部 AI / 工具条款允许本次免费公开分发与永久离线使用；不要将他人作品或付费交付包换名投稿。
- 确认包内 ID 是该作品的平台 ID，所有文件均在 manifest 中声明，没有多余字段、目录或隐藏文件。
- 公开昵称、作品介绍、预览、署名和下载素材会公开；上传前移除素材元数据中的私密信息，不放入账号密码、恢复码、会话信息、购买凭据或私钥。
- 上传校验与预览不代替版权审核，不承诺素材不可复制，也不能作为已经发布或双端运行已通过的证明。
- 登录用户名、密码摘要、恢复码摘要、会话及上传 / 审核 / 举报资料的处理范围见 `website/privacy.html#creator-community`；不以未声明的固定保留天数承诺删除。

这份指南不改变原官方付费 FAQ、价格、交易或安装锚点；功能开放、实际交付接入与运行验收由主任务另行处理。
