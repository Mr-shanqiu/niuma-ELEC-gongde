# 形象制作与免费投稿指南

更新：2026-10-30。当前双端正式客户端为0.9.5，支持合法本地自制数据包导入。投稿只通过抖音群管理员人工接洽；旧创作者工作台、在线上传、自动审核和贡献码业务继续暂停。

## 制作、校验与本地导入

使用公开的 [gongde-appearance-pack Skill](https://github.com/Mr-shanqiu/gongde-appearance-pack)，当前版本1.3.3。规范、模板、制作工具和双端制品绑定以该固定版本中的SKILL.md、references和client-baseline.json为准。官网[创作区](https://gongde.zqscreen.cn/support.html#creation)提供安装指令、ZIP及群二维码。

Skill包含统一形制、模板、静止与动作预览、校验和打包工具。制作端需要Node.js 18或更新版本，无需npm install；普通用户导入时不需要Node.js。合法DIY包使用独立diy.*身份，不包含平台license；官方保留身份仍须平台签名。本地制作与导入无需账号、联网或投稿。

制作预算：普通ZIP压缩最多8 MiB、展开最多12 MiB、manifest最多64 KiB；根目录最多8个文件、最多6图层，每层最多8关键帧；静态非交错8位RGB/RGBA PNG，单边最多2048像素，总解码最多64 MiB。制作预算不是填满限额的建议。请用Skill工具检查完整动作和文字安全区域，保留原始材料，预览输出放在源目录之外。

校验通过后分别导入相应客户端检查；静态格式通过不能代替实际动作效果验收。Skill通过明确安装新版本更新自身，不自动更新客户端或作品。

制作和自行导入不要求投稿。希望投稿时，到官网创作区查看完整现行协议，并复制群内投稿用语。将同一份.nmgpack、静止预览、动作录屏、公开署名和源素材权利说明一并交群管理员；作品ID、版本和SHA-256由工具或管理员随确认消息保存。
