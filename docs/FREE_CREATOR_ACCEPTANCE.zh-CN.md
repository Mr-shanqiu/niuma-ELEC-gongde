更新：2026-10-09。产品规则以 `docs/PRD_FREE_DOWNLOAD_AND_CO_CREATION.zh-CN.md` 1.1 及用户后续明确决定为准；实际完成状态、阻塞和部署事实以 `WORK_PLAN.md` 及绑定产物的原始回执为准。本文件定义验收范围，不以文档更新冒充功能上线。

## 1. 当前产品合同

当前执行的是全免费版本，不是历史统一收费版本。旧的“每个 0.2 元、每批封顶 1 元、首版平台收取全部费用、24 小时内首次导入”等描述不再作为新领取、新投稿或发布门槛。

| 场景 | 当前要求 | 不允许的替代行为 |
| --- | --- | --- |
| 客户端及基础木鱼 | 直接免费下载；基础木鱼随客户端可离线使用 | 要求进群、验证码、登录、付款或推广码后才能下载基础客户端 |

| 群码领取 | 输入当前群码，领取所选扩展形象；群码每三天轮换 | 把群码当成自动确认抖音关注或入群身份的凭据 |
| 作者码领取 | 作者只有一个推广码；有效贡献 N 对应每批上限 min(3*N,10) | 每次投稿额外创建推广码，或把权限做成可耗尽的余额 |

| 批次限制 | 所有来源形象合并选择，每批绝不超过十个；作者码还受自身上限约束 | 绕过服务端校验，仅在页面限制；超过十个拆成未获授权的批次 |
| 交付 | 一次领取得到一个可整批导入的文件；签名覆盖授权、内容和版本 | 要用户逐个重复点击下载，或依赖客户端联网确认付费 |

| 创作者 | 手机验证登录，可持久登录；发布新作品及更新已有作品两条路线 | 要求用户填写内部投稿 ID、额外昵称或作品短名 |
| 作者抖音号 | 投稿时可选公开本人抖音号 | 强制提供抖音号，或把抖音资料当成已验证的身份声明 |

## 2. 两条真实用户路线

### 2.1 普通使用者

1. 打开官网，直接下载对应系统客户端，安装后使用基础木鱼。
2. 在统一形象库浏览、播放动作或按通用编号查找形象。官网展示开发者抖音入口和取码指引，不声称自动验证关注关系。
3. 选择扩展形象，进入同一领取页。免费领取入口不得藏在旧付款选项内。
4. 输入群码或作者推广码；服务端返回实际可用权限和批次上限。错误码、过期码、暂停码和网络错误给出各自明确提示，不生成假权益。
5. 确认所选形象符合码权限、数量及文件大小限制，免费领取一个批次文件。领取过程给出明显状态和可重试错误，不要求付款。
6. 在 Mac 或 Windows 用普通用户方式导入；多件进入同一选择窗口，可真正切换渲染，不只是显示“导入成功”。
7. 正常退出再打开，导入形象和选择仍保留。有效包在离线环境可以导入、加载和使用，不联系官网验证付费或推广码。
8. 码在下一周期更新后，可重新获取当期码领取新批次；已下载的签名包、已导入形象和本地计数不失效。

### 2.2 共创作者

1. 无需登录或预建作品，下载制作指南文件包，交给外部 AI 或制作工具生成符合目标格式的 `.nmgpack`。
2. 手机验证码登录；登录按钮明显、错误可理解，不要求先取内部账号标识。展示稳定简短作者编号，用户不填写昵称。
3. 选择“发布新作品”，上传封装文件，填写作品名称、短介绍及可选本人抖音号等必要资料。内部作品标识由系统产生。
4. 核对真实预览，明确确认素材合法授权、免费公开分发和云端 AI 审核声明。上传、预览或页面刷新不得错误清除刚确认的有效状态；服务端仍核对实际条款版本及预览修订号。
5. 提交后显示当前版本的真实校验和审核状态。程序安全校验在 AI 审核之前，AI 不通过、异常或缺失结果不能直接上架。
6. 自动审核通过后，公开作品取得稳定通用编号；有效贡献按规则只记一次。贡献、唯一推广码、当前每批权限及三天轮换说明在工作台可见。
7. 作者复制推广码分享，其他持码人可领取任意符合规则的扩展形象，不限该作者的作品；使用不扣权限。
8. 选择已有作品进入“优化更新”。保留原资料，按需要上传新包或调整元数据，填写更新说明；用户不创建新内部 ID。
9. 更新形成可审核的独立版本，不自动增加同一作品贡献。尚未通过的新版本不得替换公开版本或已领取记录锁定的版本。
10. 作者可以持续查看自己作品及审核结果。异常件由管理员处理，不要求普通作者参与后台运维。

## 4. 安全和审核边界

- 形象包是数据包，不是插件或代码扩展。不得执行投稿中的脚本、二进制文件、HTML、命令、外链或自动安装逻辑。
- 先做程序化结构安全校验，再进入经过明确授权的 AI 内容审核；不能靠 AI“看起来安全”替代路径、类型、大小、解压及解码限制。
- 拒绝路径穿越、绝对路径、重复/歧义项、链接、超限压缩包、未知执行类条目和非法图层/帧数据。
- 当前原有校验限制包括：上传 ZIP 最多 8 MiB、解压总量最多 12 MiB、manifest 最多 64 KiB、条目最多八项、PNG 边长最多 2048、解码预算最多 64 MiB、图层最多六层、动作帧最多八帧。若目标格式正式调整，须同时更改指南、服务端和客户端，不单独放宽某一端。
- 当前画布素材区为 y >= 0、y + height <= 170；素材不能覆盖反馈和计数区。真实 PNG 解码、预览及客户端渲染必须与锁定 manifest 对应。
- 无效包、安全拒绝或审核失败不得产生有效贡献和公开分发资格。AI 服务超时、错误或无结果应保留可追踪状态，不能按通过处理。
- 已审核版本不可被原位改字节。更新、下架和账号/作品暂停须按既有不可变版本及分发规则处理，不能修改已下载的本地文件。
- 密钥、手机号、验证码、Cookie、原始私有载荷、共享码明文和未脱敏日志不进入公开文档或 Git。

## 5. 链接、保存期与历史履行

永久离线授权与服务器下载可用期不是同一概念。当前领取文件保存七天，下载地址有效期不超过五分钟；领取过期或短链失效不缩短已下载包的使用期限。符合规则的用户可用当期有效码重新领取。

清理按数据库引用及至少十四天的保守条件处理，由既有十五分钟 worker 执行；不通过桶级生命周期误删仍被有效领取或历史履行引用的对象。空扫描/零删除只能证明该轮没有符合条件的对象，不能证明已真实删除过期文件。

停止新收费不是删除历史履行。原有效订单、已取得权益及冻结交付版本继续按历史承诺处理。禁止为验收新免费版本制造新的真实付款、伪造支付回调或改变旧订单状态。
