# 招财猫与本机原生效果统一：待发布

## 已确认的差异

- 本机 `/Applications/牛马电子功德.app` 为 0.5.2，仍带原生招财猫素材。
- 安装版、原生源目录、正式形象包的身体与手臂 PNG 分别逐字节相同，不重新绘制。
- 线上 1.0.0 包把两层都放在 `[35,0,170,170]`，手臂下降 12；原生 Mac 身体 `[5,-35,230,230]`、手臂 `[30,-35,230,230]`，固定肩膀后纵向缩短 20%。
- 此前网站与下载源指纹一致，仅证明两者采用同一个包，不证明该包与旧版内置招财猫相同。

## 本次实现

- 招财猫 1.1.0 的 manifest 直接表达上述原生 Mac 几何、肩膀锚点和 0/0.42/1 三阶段动作。Windows 和网站使用同一份定义，不再分别调位置。
- schema 3 每层必须声明 `interpolation`（linear 或 smoothstep），每关键帧必须声明 `scale_y`（0.1..4）。横向缩放仍为 scale，纵向为 scale * scale_y。
- schema 1/2 保持原有字段与线性插值。schema 3 可为未签发源或带 license 的限时交付包；有 license 时仍执行原有验签与首次导入期限检查。
- schema 3 允许透明素材画布越出形象区域；实际绘制继续裁切在 240x170 内，不能盖住 +1 或计数。Mac 的上层视图和 Windows 绘制函数保留裁切，网页 canvas 自身限定尺寸。
- 制作工具、签发服务、两端播放器、网站播放器同步支持；缩略图由 manifest 静止帧生成，不另画一张图。

## 发布门槛，尚未通过

本轮仅改本地源码及生成预览资源；没有编译或安装客户端，没有运行测试，没有发布网站、API 或付费包。不得称为已经上线或双端验收通过。
