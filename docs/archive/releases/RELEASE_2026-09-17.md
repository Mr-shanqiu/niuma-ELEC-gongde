# 0.9 手机号资格与付费形象方案实施记录

日期：2026-09-17

## 已完成的源码范围

- 基础客户端收缩为只内置木鱼；招财猫、仓鼠跑轮、海狮拍肚皮和小鸡啄米统一改为官方付费形象包。
- macOS 与 Windows 升级时如仍保留旧的内置动物选择，会安全回落到木鱼；已导入的正式形象包不受影响。
- 取消微信开放平台网站登录方案，改为中国大陆手机号短信验证码身份。
- 将收费拆分为三类独立订单：100分官方形象库资格、20分形象包生成与下载、100/500/1000分自愿赞赏。
- 首次购买官方资格包含当前形象包；以后每次生成一个新形象包为20分。
- 赞赏不要求手机号，不发放商品、功能或其他权益。
- 手机号标准化后只用于短信发送；订单绑定服务端 HMAC 内部用户标识，不把手机号传给客户端。
- 验证码5分钟有效、最多错误5次、60秒重发冷却；同手机号每天10次、同IP每小时20次、全局每天1000次，日额度按北京时间自然日计算。
- 形象包交付资格写入24小时有效期；官方形象库资格本身不设到期时间。
- 官网补充无广告、成本说明、手机号购买流程和独立赞赏入口。

## 安全与运行边界

- `GONGDE_SMS_MODE` 和 `GONGDE_PAYMENT_MODE` 默认均为 `disabled`。
- `mock` 只做本地模拟，不发送真实短信、不调用支付渠道。
- 腾讯云短信正式适配器已经加入，并支持从只读文件加载密钥以及复用【智家】签名和现有模板。
- 短信 `live` 已改用独立 Redis 原子状态机，不使用进程内状态承载正式验证码。
- Redis 中只保存 HMAC 标识；发送额度预占、结果不明阻断、五次错误锁定、一次性消费和30天会话均为原子操作。
- 新增独立 MySQL 订单存储、事务边界与初始 migration；正式订单、支付结果和交付权益以 MySQL 为唯一真相。
- MySQL 密码只从只读文件加载，功德必须使用独立 database 和最小权限用户。
- 新增 `/api/live` 与依赖感知的 `/api/ready` 健康检查。
- 新增 Node 原生 P-256 形象包签发器；支付完成后可按 `asset-download` 权益动态生成24小时 Schema 2 数据包。
- 私钥只从只读文件加载，下载响应禁止缓存，客户端继续使用内置公钥离线验证。
- 支付 `live` 仍拒绝启动，直到持久化、回调和生产验收完成。
- 桌面客户端没有改动，仍然完全离线、无广告、无遥测。

## 桌球短信能力复用结论

- 可复用腾讯云短信 provider、Redis 原子状态机、验证码与防重放设计。
- 不可复用桌球 `/api/merchant/send-code`、`/api/merchant/verify` 或其门户会话。
- 用户确认复用【智家】签名与现有通用登录验证码模板，不再申请独立签名或模板。
- 功德仍使用独立 `gongde_login` purpose、发送路由、验证码状态、登录会话和订单数据。
- 配置优先读取 `TENCENT_CLOUD_SMS_GONGDE_SIGN_NAME`、`TENCENT_CLOUD_SMS_GONGDE_LOGIN_TEMPLATE_ID`，未设置时回退到桌球现有签名和模板配置。
