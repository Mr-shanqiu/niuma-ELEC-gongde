# 牛马电子功德免签名公开测试版

本次统一发布 Windows 与 macOS 0.6.0。两个客户端均为原生、无音效、离线运行的桌面小工具。

## 核心功能

- 统计全局键盘按下、所有鼠标按键和明确的滚轮手势次数。
- 数字即时增加，动画限速且不积压。
- 每日功德、历史总数和功德日历。
- 中英文界面、登录后自动启动、四个内置形象。
- 离线 `.nmgpack` 形象包导入、更新、选择和删除。
- 不包含联网、广告、遥测、账号、支付或自动更新。

## 验收状态

- macOS 0.6.0：Universal 2（Intel + Apple Silicon）构建、自动化功能测试、离线审计、DMG 校验和本机真实运行通过。
- Windows 0.6.0：Windows Server 2022 + MSVC Release 构建、形象包运行测试、离线审计和一台 Windows 真机验收通过。
- 不宣称已覆盖所有 Windows/macOS 版本、Intel Mac 真机或多显示器组合。
