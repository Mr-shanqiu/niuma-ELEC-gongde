只有某些窗口不计数？

UAC、安全桌面、密码输入和部分高权限窗口受到系统保护。请在普通应用中确认计数；无需为此长期以管理员身份运行，或关闭系统保护。

遇到其他安全拦截怎么办？

如果 Mac 提示应用“已损坏”或“将损坏你的电脑”，或 Windows 提示恶意软件、智能应用控制或组织策略阻止，请先停止安装，保留提示并联系开发者。无需关闭系统安全保护。
