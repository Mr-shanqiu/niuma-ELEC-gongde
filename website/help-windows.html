正常打开，
不必寻找“输入监控”开关。

Windows 10 / 11 没有 Mac 那样的“输入监控”授权开关。普通使用通常不需要额外权限，也不需要把客户端长期设为管理员运行。

先记住这一条：从正式安装后的快捷方式打开客户端，在普通应用中正常使用。不要为增加计数关闭 UAC、防病毒或其他系统保护。

普通使用，不需要设置一堆权限

  1. 从官网下载并安装牛马电子功德，使用安装后的桌面或开始菜单快捷方式打开。
  2. 小伙伴出现后，在普通记事本、浏览器等应用里打字或点击鼠标，功德会随操作增加。
  3. 右键小伙伴可以打开“关于”、开启或关闭自启动、更换形象、查看功德日历或退出。

无需开启 Windows 的“墨迹书写和键入个性化”、诊断数据、麦克风或摄像头权限。那些设置不是本软件全局计数的授权入口。

只有点击小伙伴时数字增加？

点击计数可用，不等于其他应用中的输入也已被接收。先按下面的短流程处理，不必删除软件数据：

  1. 右键小伙伴选择“退出”，再从正式安装的快捷方式重新打开；不要同时运行下载目录中的旧副本。
  2. 在普通记事本中输入几个字，或正常点击桌面。不要用登录界面、UAC 提示或密码输入窗口判断全局计数。
  3. 如果普通应用中正常，只在某个特殊窗口中不计数，先查看下方的系统权限边界。
  4. 如果普通应用中仍没有计数，保留“关于”中的客户端版本、Windows 版本和出现的提示，联系项目。不要清空功德、日历或形象文件。

客户端没有独立“权限检查”或“计数自检”入口，不需要到菜单里寻找这些按钮。

有些窗口受到 Windows 系统保护

UAC 确认窗口、安全桌面，以及不同权限级别的应用，存在系统访问边界。普通应用中的操作正常计数，并不保证所有高权限或安全窗口中的操作都能计数。

遇到这种情况，优先在普通权限运行的应用中使用。不要关闭 UAC 或安全桌面，不要为计数绕过系统保护，也不建议把桌面小伙伴始终设为管理员运行。

如果电脑由公司统一管理，部分限制可能由组织策略决定，请遵守组织规定，不要修改安全策略来扩大监听范围。

更新应用，不清空你的积累

  1. 先在小伙伴的右键菜单中选择“退出”。
  2. 用官网新版安装程序更新原安装位置，不同时运行新旧副本。
  3. 正常重开后，在“关于”查看版本；原计数、日历和导入形象不应因更新而需要清空。

本软件没有自动更新。安装相关问题请查看Windows 安装与导入说明；不要按 Mac 的输入监控步骤寻找 Windows 的授权开关。

只统计次数，不记录输入内容

牛马电子功德用按键、鼠标按键和滚轮事件进行计数与动画，不保存具体按键内容、鼠标坐标、当前应用或窗口内容。计数、日历和已导入形象保存在本机，客户端无需联网运行。

点击“关于”中的帮助链接，由默认浏览器打开本页，不会把客户端计数或输入记录发送到官网。本页也不会替你修改系统权限、下载安装程序或开启远程控制。
