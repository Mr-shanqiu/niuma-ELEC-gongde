# 官网 0.8.0 部署说明

这是牛马电子功德官网前端。基础下载保持静态、免费且免登录；付费形象使用独立的手机号短信验证、订单和支付服务。桌面客户端保持完全离线。

- 入口：`index.html`
- 正式域名：`https://gongde.zqscreen.cn`
- 下载域名：`https://download.gongde.zqscreen.cn`
- macOS：0.7.0 Universal 2，DMG 与 ZIP 独立分发。
- Windows：0.6.0 x64 ZIP，独立分发。
- 基础安装包只内置木鱼。其他形象由付费交付服务动态签发，不放入静态下载目录。
- 部署：运行 `./scripts/package-website.sh` 生成冻结站点归档和下载清单，不要把安装包塞入站点归档。
- 健康检查：`GET /healthz.txt` 返回 `200 text/plain`，正文为 `gongde-ok`。
- 容器：纯静态 HTTP，端口 `8080`，只读文件系统，建议上限 `0.10 CPU / 64MiB`。
- 身份：不使用微信开放平台登录；购买资格绑定短信验证后的手机号内部标识。
- 商品：官方形象库资格100分，首次可选1至10个形象包；后续每批1至10个形象包生成与下载统一20分。
- 赞赏：100/500/1000分可选，不要求手机号，不产生任何商品权益。
- 统计：只使用完成服务和安全防护所需的服务器记录，不加入第三方广告或行为追踪脚本。

真实短信、真实支付、持久化订单和创作者功能尚未启用。页面通过 `?payment_test=1` 提供纯本地模拟，不发送短信、不创建真实订单、不扣款。
