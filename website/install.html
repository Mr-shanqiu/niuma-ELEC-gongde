安装前先确认来源

Verify the source first

只从 gongde.zqscreen.cn 或项目公开仓库下载。当前版本没有 Apple 或 Microsoft 商业代码签名，系统可能显示未知开发者或未知发布者。请先核对官网公布的 SHA-256。

Download only from gongde.zqscreen.cn or the public project repository. This preview is not commercially code-signed, so your system may show an unknown-developer warning. Verify the published SHA-256 first.

macOS

  1. 打开 DMG，将“牛马电子功德”拖入“应用程序”文件夹。
  2. 从“应用程序”打开。如果系统阻止启动，进入“系统设置” → “隐私与安全性”，核对名称和来源后点击“仍要打开”。
  3. 进入“系统设置” → “隐私与安全性” → “输入监控”，允许“牛马电子功德”。
  4. 完全退出软件后重新打开。无需重新启动电脑。
  1. Open the DMG and drag NiuMa Merit into Applications.
  2. If macOS blocks it, open System Settings → Privacy & Security, verify the app and source, then choose Open Anyway.
  3. Open System Settings → Privacy & Security → Input Monitoring and enable NiuMa Merit.
  4. Quit the app completely and reopen it. A computer restart is not required.

出现多个同名权限条目

Duplicate permission entries

退出全部旧进程，删除旧副本，只保留“应用程序”中的最新版；移除旧权限条目后重新打开最新版并允许一次。更新时应始终替换同一位置的软件。

Quit all old copies, remove duplicates, and keep only the current app in Applications. Remove stale permission entries, reopen the current copy, and enable it once.

Windows

  1. 下载 ZIP 并完整解压到固定文件夹，不要在压缩包内直接运行。
  2. 启动软件。只有文件来自官网且 SHA-256 一致时，才在 SmartScreen 中选择“更多信息” → “仍要运行”。
  3. Windows 通常不会显示单独的输入监控授权窗口，启动后即可统计普通桌面中的键鼠操作。
  1. Download the ZIP and extract it to a permanent folder. Do not run it from inside the archive.
  2. Launch the app. Use More info → Run anyway only when the file came from the official site and its SHA-256 matches.
  3. Windows normally shows no separate input-monitoring prompt. Counting begins after launch in the normal desktop session.

不要永久关闭杀毒软件。登录界面、UAC 安全桌面和部分高权限程序中的输入不会被统计。

Do not permanently disable antivirus protection. Input on the sign-in screen, UAC secure desktop, and some elevated apps is not counted.

为什么需要输入监控

Why Input Monitoring is required

准确说明：macOS 的这项权限在技术上允许获授权的软件接收更丰富的输入事件。系统不能只授权“次数”。安全边界来自软件实际如何处理事件，而不是权限名称。

The precise explanation: this macOS permission can technically expose richer input events. macOS cannot grant count-only access. The safety boundary is how the app handles events, not the permission label.

本软件只把键盘按下、鼠标按键和独立滚动手势转换成计数。它不保存具体按键、输入文字、鼠标位置、窗口标题、软件名称、剪贴板、截图、文件内容、密码、设备标识或遥测数据。

The app converts key presses, mouse buttons, and distinct scroll gestures into counts. It does not save specific keys, typed text, pointer positions, window titles, app names, clipboard data, screenshots, files, passwords, device identifiers, or telemetry.

安装形象包

Install appearance packs

  1. 从官网下载扩展名为 .nmgpack 的形象包。
  2. 双击形象包，让系统交给“牛马电子功德”导入。
  3. 右键桌面形象，选择“更换形象”，点选已安装形象并确认。
  1. Download a .nmgpack file from the official site.
  2. Double-click it to import it into NiuMa Merit.
  3. Right-click the desktop character, choose Change Appearance, select an installed appearance, and confirm.

形象包只能包含经审核的图片、动画参数和说明信息，不能修改计数、权限、联网或其他程序功能。

Reviewed appearance packs contain images, animation parameters, and metadata only. They cannot change counting, permissions, networking, or other app behavior.

常见问题

Troubleshooting

允许权限后仍不计数

No counting after permission

完全退出后重新打开，并确认“输入监控”允许的是“应用程序”文件夹中的当前版本。

Quit and reopen the app. Confirm that Input Monitoring is enabled for the current copy in Applications.

点击形象会加一，其他输入不计数

The character counts clicks, but global input does not

这表示软件本身正在运行，但全局监听未生效。重新检查输入监控权限，并在修改后退出、重新打开软件。

The app is running, but global monitoring is inactive. Recheck Input Monitoring, then quit and reopen the app.

是否需要重新启动电脑

Must I restart the computer?

不需要。权限变更后只需完全退出并重新打开软件。

No. Quit and reopen the app after changing permissions.
