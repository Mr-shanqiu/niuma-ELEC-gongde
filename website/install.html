macOS 安装

第一次会多一步系统确认

打开 DMG，把应用拖入“应用程序”，再从“应用程序”启动。首次打开可能有系统安全提示；只有确认官网下载来源并愿意运行时，才按图解为本应用确认。不要关闭系统的全局安全保护。

01

打开下载文件

在“下载”文件夹里，双击名称以 .dmg 结尾的文件。

02

拖入“应用程序”

把左侧的木鱼图标拖到右侧“应用程序”文件夹。

03

确认后，仅允许本应用打开

遇到“Apple 无法验证”提示时，先点“完成”，不要点“移到废纸篓”。确认文件来源后，进入“系统设置 → 隐私与安全性”，找到本应用并点“仍要打开”，再按系统提示确认。

这与下一步的“输入监控”授权不同，也不需要关闭全局安全检查。如果系统提示应用“将损坏你的电脑”或“已损坏”，请停止安装，不要绕过提示。可查看 Apple 官方说明。

04

开启“输入监控”

打开开关后，应用只统计按键和点击次数，不读取你输入的文字。

Windows 10 / 11 安装

下载后，双击 EXE 安装

直接双击安装，不再需要解压 ZIP。安装程序会帮你创建快捷方式。

01

打开 EXE

在“下载”文件夹里双击官网提供的 .exe 安装包。

02

如果出现安全提醒

仅在确认文件来自官网、提示是“Windows 已保护你的电脑”且愿意运行时，点击“更多信息”，再点“仍要运行”。

没有“仍要运行”，或提示恶意软件、智能应用控制／组织策略阻止？请停止安装，保留提示截图并联系项目。不要关闭杀毒软件、全局安全保护或反复绕过拦截。

03

保持默认选项

“开机后自动启动”默认勾选。以后也可以在应用设置里关闭。

04

安装完成

从桌面快捷方式打开。需要卸载时，可在 Windows“已安装的应用”中操作。

保留你的小伙伴和积累

更新应用，不清空数据。

先退出旧版。Mac 在“应用程序”替换同名应用；Windows 使用新版安装程序更新原安装位置。不要同时运行下载目录、DMG 和正式目录中的多个副本。

重开后核对“关于”中的版本、原计数、已安装形象和自启动设置，再在其他普通应用中检查计数。系统可能要求重新确认权限，以实际监听结果为准。

软件不自动更新。安装包、源代码、签名状态和真实使用测试是不同信息；有问题时保留原安装文件与提示，回退应用但不删除用户数据。

关于开机启动

默认开启，但永远由你决定。

开机启动只是让桌面小伙伴自动出现，不会联网，也不会上传任何输入内容。Mac 和 Windows 都可以随时在应用设置中关闭。
