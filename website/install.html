macOS 安装

第一次会多一步系统确认

这是未签名测试版的正常提示。只要安装包来自官网，就按下面的步骤操作。

01

打开下载文件

在“下载”文件夹里，双击名称以 .dmg 结尾的文件。

02

拖入“应用程序”

把左侧的木鱼图标拖到右侧“应用程序”文件夹。

03

允许打开

进入“系统设置 → 隐私与安全性”，找到提示并点击“仍要打开”。

04

开启“输入监控”

打开开关后，应用只统计按键和点击次数，不读取你输入的文字。

Windows 10 / 11 安装

以后只提供 EXE 安装包

直接双击安装，不再需要解压 ZIP。安装程序会帮你创建快捷方式。

01

打开 EXE

在“下载”文件夹里双击官网提供的 .exe 安装包。

02

如果出现安全提醒

确认文件来自官网后，点击“更多信息”，再点“仍要运行”。

03

保持默认选项

“开机后自动启动”默认勾选。以后也可以在应用设置里关闭。

04

安装完成

从桌面快捷方式打开。需要卸载时，可在 Windows“已安装的应用”中操作。

关于开机启动

默认开启，但永远由你决定。

开机启动只是让桌面小伙伴自动出现，不会联网，也不会上传任何输入内容。Mac 和 Windows 都可以随时在应用设置中关闭。

给熟悉电脑的用户：查看安装包校验值

普通用户不需要操作这一项。若你希望核对文件完整性，可查看官方 SHA-256 清单。
