macOS 安装

第一次会多一步系统确认

本轮 0.9 Mac 实际新构建使用 Apple Development 签名，不是 Developer ID 分发签名，且未完成 Apple 公证。第一次打开仍可能被 Gatekeeper 阻止或提示，不能据此宣传免安全提示或已获 Apple 分发认可。只有确认官方来源、文件未被修改，并愿意运行当前版本时，才按下面步骤进行单应用确认。

01

打开下载文件

在“下载”文件夹里，双击名称以 .dmg 结尾的文件。

02

拖入“应用程序”

把左侧的木鱼图标拖到右侧“应用程序”文件夹。

03

确认后，仅允许本应用打开

遇到“Apple 无法验证”提示时，先点“完成”，不要点“移到废纸篓”。确认文件来源后，进入“系统设置 → 隐私与安全性”，找到本应用并点“仍要打开”，再按系统提示确认。

这与下一步的“输入监控”授权不同，也不需要关闭全局安全检查。如果系统提示应用“将损坏你的电脑”或“已损坏”，请停止安装，不要绕过提示。可查看 Apple 官方说明。

04

开启“输入监控”

打开开关后，应用只统计按键和点击次数，不读取你输入的文字。

Windows 10 / 11 安装

以后只提供 EXE 安装包

直接双击安装，不再需要解压 ZIP。安装程序会帮你创建快捷方式。

01

打开 EXE

在“下载”文件夹里双击官网提供的 .exe 安装包。

02

如果出现安全提醒

确认文件来自官网后，点击“更多信息”，再点“仍要运行”。

03

保持默认选项

“开机后自动启动”默认勾选。以后也可以在应用设置里关闭。

04

安装完成

从桌面快捷方式打开。需要卸载时，可在 Windows“已安装的应用”中操作。
