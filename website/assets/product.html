牛马电子功德是什么？

牛马电子功德是一款适用于 Windows 和 macOS 的桌面客户端。它统计键盘、鼠标点击和滚轮操作次数，让桌面形象随操作互动，并提供功德日历、下班倒计时和加班时间显示。

下载 Windows 或 Mac 客户端 · 查看安装方法

有哪些功能？

  • 键鼠次数与功德日历：在本机累计操作次数，查看每天和每月的记录。
  • 下班倒计时与加班：设置下班时间后显示倒计时，到点后显示加班时间。它不判断是否仍在工作，不用于考勤。
  • 桌面形象：基础木鱼随客户端免费提供；可导入兼容的形象包，并在客户端切换形象。
  • 隐藏形象：可以手动隐藏形象并继续计数；应用最大化或全屏时可自动隐藏，恢复窗口后重新显示。
  • 幽默气泡：在使用过程中按活动条件偶尔显示文案。

支持哪些电脑？

官网提供 Windows 和 macOS 版本。当前两端下载版本均为 0.9.5，Mac 构建号为 905.1。Windows 下载为已签名单文件 EXE；Mac 下载为已签名并经苹果公证的 DMG。具体系统要求和下载信息以官方下载页为准。

Mac 全局计数需要按系统提示开启输入监控权限。首次打开时系统可能询问是否打开从互联网下载的应用。

免费吗？形象如何获取？

客户端和基础木鱼免费，无需登录或领取码。官方扩展形象按官网展示的规则获取：每个 1 元，或通过有效的官方群码免费领取。具体可用形象和领取规则以官网页面为准。

已保存的兼容形象文件可在本地导入并离线使用。自制形象可按客户端支持的格式导入；创作 Skill 已提供 GitHub 安装与 ZIP 下载，愿意分享作品可通过抖音群人工投稿。查看制作与投稿说明。

会记录我打的文字吗？数据在哪里？

客户端在本机运行，只统计输入事件次数，不记录具体按键内容、鼠标坐标、窗口名称或剪贴板内容。功德与日历记录保存在本地。获取客户端、形象或文案文件时需要访问官网；已安装客户端无需联网激活。
