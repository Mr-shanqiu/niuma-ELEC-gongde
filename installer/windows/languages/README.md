# Installer translation

ChineseSimplified.isl is the unmodified community translation distributed in
the official Inno Setup source repository, pinned to release is-6_2_2:

https://github.com/jrsoftware/issrc/blob/is-6_2_2/Files/Languages/Unofficial/ChineseSimplified.isl

Original translation attribution is retained in the file. Vendoring this file
avoids depending on a Chinese translation being bundled with the CI compiler.
